# Eagle Day submission checklist

- Working local or hosted demo.
- Source ZIP or repository without secrets, credentials or dependency caches.
- README with exact setup and run steps.
- Short problem statement naming the audience and task.
- Before and after screenshots from the changed path.
- Two reference links and the pattern-choice reasoning.
- Test notes including one failure and correction.
- Visible list of mocks, incomplete routes and known gaps.

Prepare your demo link, source package, setup notes and evidence for the reviewer assigned at the fireside.
